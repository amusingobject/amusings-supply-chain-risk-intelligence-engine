# Expected outputs

This directory is frozen truth. Benchmark runs must write to `runs/` (and optional `reports/`), never here.

Scenario gold expectations are also embedded in each scenario manifest and indexed by `scenarios/index.json`. Identity-pair gold lives in `identity/T02.json`. Atomic labels remain provisional until lawful collection and human adjudication. In a locked benchmark, holdout expected outputs must be access-controlled outside model-development workflows.
